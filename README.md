# WebTab
WebTab is a self-contained browser start page that combines a dark glassmorphism aesthetic with practical daily navigation. Structurally, the HTML separates the display into a fixed background layer holding the wallpaper and an overlay canvas, along with a vertically centered container housing a digital clock, a direct Google search form, and a row of quick-access shortcut buttons. Visually, the CSS color system builds depth by layering translucent white surfaces with varying opacities and backdrop blurs over a deep black canvas, accented by soft border highlights and responsive hover transitions. Under the hood, plain JavaScript powers the experience without external dependencies: it updates the digital clock and localized date every second, parses bookmark domain names to dynamically fetch crisp icons from Google's favicon service, and drives a lightweight canvas animation loop that renders and continuously cycles drifting star particles across the screen.Also added notes.
